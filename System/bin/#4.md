# 游戏总线
依赖节点的 _ready 和 _process 实现功能
导致大部分操作都是异步进行的
所以维护一个全局总线状态机来避免异步系统的潜在问题

预加载（Preloading）：全局管理器初始化和全局数据加载
主菜单（MainMenu）：主菜单界面，过渡状态
加载（Loading）：场景初始化/存档数据加载
运行（Running）：包括 3 个子状态
Control：玩家自由操作，禁止鼠标输入，正常游戏状态；
Auto：禁止任何输入，用于播放过场动画；
Menu：允许鼠标输入，用于游戏内UI操作。

只有 MainMenu 和 Running 两种状态下可以退出游戏
避免数据加载过程中退出游戏导致数据异常

# 数据层：基于Resource的数据管理
Resource 作为 Godot 内置的自定义数据存储类
可以比较方便的实现大部分游戏数据的管理

GameData：存储游戏内的全局变量
PlayerData：存储玩家属性/背包/状态变量
SceneData：存储场景动态节点状态/属性变量
以上三种数据都会以JSON文件的形式
写入存档数据（ArchiveData）里

ConfigData：存储跨存档的系统变量（最上层）
